##  Project Overview

This project is **Task 4 – Dashboard Design** of my Data Analytics internship. Using the Superstore Sales dataset, I built a clean, interactive dashboard that shows key business metrics, sales trends and profit performance in one place.

##  Objective

Design an interactive business dashboard to analyze sales and financial performance and support business decision-making.

##  Tools & Technologies

| Tool | Purpose |
|------|---------|
| Microsoft Power BI | Dashboard design and visualization |
| Kaggle | Dataset source |
| CSV | Data format |
| PowerPoint | Dashboard summary presentation |

##  Dataset

- **Name:** Superstore Sales Dataset (`Sample - Superstore.csv`)
- **Source:** Kaggle
- **Contains:** Order, sales, profit, quantity, region, category and sub-category information used for the analysis.

##  Dashboard Features

**KPIs**
-  Total Sales
-  Total Profit
-  Total Quantity
-  Sales Growth

**Visuals**
-  Monthly Sales Trend
-  Sales by Category
-  Sales by Region
-  Profit by Sub-Category

**Interactivity**
-  Slicers for **Order Date**, **Region** and **Category**

##  Key Business Insights

The dashboard helps users to:

- Track overall sales, profit and quantity at a glance
- Observe how sales change month by month
- Compare sales across categories and regions
- Identify which sub-categories contribute more or less profit
- Filter the data by date, region and category to explore specific areas
